- Koopman理论的哲学动机
  - 非线性系统在有限维状态空间难以统一处理
  - 转而考察无穷维"观测函数空间"，在此空间上动力学是线性的
  - 本质：用函数空间的视角"提升"问题层次，以无穷维线性代价换取对非线性的统一描述
  - 实践定位：天然适合数据驱动框架，是动力系统理论与现代数据科学的桥梁，既能对接追求可解释性的统计学习，也能对接追求精度的机器学习

- Koopman算子的基本概念
  - 基本设置
    - 给定动力系统，flow map将初始状态沿轨迹推进，即 $x(t) = F^t(x(0))$
    - Koopman算子作用于观测函数空间，定义为 $\mathcal{K}^t g(x) = g(F^t(x))$
    - 含义："先演化状态再观测"等价于"先观测再作用算子"
  - 线性性的来源
    - Koopman算子满足 $\mathcal{K}^t(\alpha_1 g_1 + \alpha_2 g_2) = \alpha_1 \mathcal{K}^t g_1 + \alpha_2 \mathcal{K}^t g_2$
    - 线性性来自复合结构本身，与底层动力学是否非线性无关
  - 函数空间的选取
    - 通常不预先严格指定，只要求满足向量空间、内积、完备性等性质
    - 现代常用Hilbert空间，如 $L^2$ 或再生核Hilbert空间（RKHS）
    - 空间选取会影响算子的性质及其数值近似的行为
  - 离散与连续时间
    - 离散时间：单步算子 $\mathcal{K}$ 诱导线性动力系统 $g_{k+1} = \mathcal{K} g_k$，与非线性的 $x_{k+1} = F(x_k)$ 类比
    - 连续时间：存在无穷小生成元 $\mathcal{L}$（Lie算子），满足 $\mathcal{L}g = \nabla g \cdot f$，即观测函数沿向量场的导数
    - 生成元诱导函数空间中的线性演化方程 $\dot{g} = \mathcal{L}g$
  - 对偶视角
    - Lie算子的伴随称为Liouville算子（常见于Hamilton动力学）
    - Koopman算子的伴随称为Perron-Frobenius算子，作用于概率密度函数空间

- 核心张力与实践出路
  - 根本矛盾：状态空间有限维但函数空间无穷维，线性化以无穷维为代价
  - 坐标变换的两种方向
    - 几何动力学要求同胚/微分同胚，但全局同胚几乎不可能存在
    - Koopman框架采用"嵌入"：将状态提升至更高维空间，允许展开非线性，不要求可逆
  - 实践核心问题：寻找有限维的Koopman不变子空间，使动力学在其上近似线性
  - 警示：选错函数基会导致完全失效——如Logistic映射在多项式基下，每步迭代需要更高阶多项式（Pascal三角形结构），朴素截断对混沌系统无效
 
- Koopman不变子空间与有限维表示
  - 定义
    - 若一组函数 $\{g_1,\dots,g_p\}$ 张成的子空间在Koopman算子作用下保持封闭，则称为不变子空间
    - 将算子限制到不变子空间上，可得有限维矩阵表示，诱导有限维线性系统
    - 实践中通常只能找到近似不变子空间
  - 特征函数坐标是构造不变子空间的核心途径
    - Koopman特征函数 $\varphi$ 满足 $\mathcal{K}\varphi = \lambda\varphi$（$\lambda$ 为对应特征值），是"随时间线性演化"的观测量
    - 在特征函数坐标下，动力学退化为对角线性系统，这正是"用线性处理非线性"的具体实现
    - 任意有限个特征函数的张成空间必然是不变子空间
    - 特征函数提供内禀坐标，在坐标变换下保持不变，谱结构是动力系统的内在不变量
    - 两个特征函数之积仍是特征函数，特征值为原特征值之积（离散时间）或之和（连续时间生成元）
    - 复共轭特征函数对的乘积给出实值特征函数，对应特征值为 $\lambda + \bar{\lambda} = 2\text{Re}\{\lambda\}$（连续时间生成元下为特征值之和）
  - 典型例子
    - 系统：$\dot{x}_1 = \mu x_1$，$\dot{x}_2 = \lambda(x_2 - x_1^2)$，其中 $\lambda < \mu < 0$
    - 提升坐标 $y = [x_1, x_2, x_1^2]^\top$，引入非线性观测量 $g = x_1^2$ 封闭系统
    - 动力学精确线性化为三维对角系统
    - 对应Koopman特征函数为 $\varphi_\mu = x_1$ 和 $\varphi_\lambda = x_2 - b x_1^2$
    - 常数 $b = \lambda/(\lambda-2\mu)$ 反映有限速率比下轨迹跟随吸引慢流形的程度

- 特征函数的几何意义与计算
  - 水平集的物理意义
    - 写特征函数和特征值为极坐标形式：$\varphi(x) = R(x)e^{i\Theta(x)}$，$\lambda = re^{i\theta}$（$R(x)$ 为模，$\Theta(x)$ 为辐角，$r$ 为特征值模，$\theta$ 为特征值辐角）
    - 模的子水平集映射关系：$F(M_\varphi(C)) = M_\varphi(rC)$，其中 $M_\varphi(C) = \{x: R(x) \leq C\}$
    - 辐角的子水平集映射关系：$F(A_\varphi(\alpha)) = A_\varphi(\alpha+\theta)$，其中 $A_\varphi(\alpha) = \{x: \Theta(x) \leq \alpha\}$
    - 特征值为1时，水平集在flow map下不变
    - 特征值在单位圆上且相位为有理数 $\theta/2\pi = p/q$ 时，水平集构成 $q$ 周期轨道链
  - isostable与isochron
    - isostable（等稳线）：特征函数模 $|\varphi|$ 的水平集，捕捉振荡轨迹的指数包络，刻画收敛速率
    - isochron（等时线）：特征函数辐角 $\arg(\varphi)$ 的水平集，收集以相同相位收敛的初始条件
    - 对焦点型平衡点，两者构成极坐标（action-angle）系统
    - 对鞍点型平衡点，两者构成笛卡尔坐标系统
    - 是非线性降阶和振荡器同步控制的基础工具
  - 特征函数的计算方法
    - 谐波/Fourier平均法：$\tilde{g}_\omega(x) = \lim_{T\to\infty} \frac{1}{T}\int_0^T g(F^t(x))e^{-i\omega t}dt$，适用于单位圆上的特征值
    - PDE法：特征函数满足 $\nabla\varphi(x) \cdot f(x) = \mu\varphi(x)$（$\mu$ 为对应特征值，$f(x)$ 为向量场），可通过级数展开（Taylor/Laurent）或数据回归近似求解
    - 特征函数比Koopman模态更难计算，是extended DMD等高级算法的动机

- Koopman模态分解（Koopman Mode Decomposition, KMD）
  - 核心思想
    - 将可观测量的时间演化分解为"空间模式+时间动态"的线性叠加
    - 类似傅里叶分解，但基函数由系统动力学内禀决定，自动适应非线性结构
  - 基本公式
    - 向量可观测量 $g(x)$ 可展开为（$v_j$ 为Koopman模态向量）：
      $$g(x) = \sum_{j=1}^\infty \varphi_j(x) v_j$$
    - 时间演化（离散时间）：
      $$g(x_k) = \sum_{j=1}^\infty \lambda_j^k \varphi_j(x_0) v_j$$
    - 时间演化（连续时间）：
      $$g(x(t)) = \sum_{j=1}^\infty e^{\lambda_j t} \varphi_j(x_0) v_j$$
  - 三元组的含义
    - $\lambda_j$：Koopman特征值，决定频率与增长/衰减率
    - $\varphi_j(x)$：Koopman特征函数（标量函数），给出时间权重，满足 $\mathcal{K}\varphi_j = \lambda_j \varphi_j$
    - $v_j$：Koopman模态（向量），表示空间上的相干结构
  - 物理意义
    - 当 $g(x)=x$ 时，$v_j$ 是物理空间中以相同频率 $\lambda_j$ 振荡的相干模式
    - $\varphi_j(x_0)$ 表示初始条件对第 $j$ 个模态的激发程度
    - 实现"空间-时间分离"：空间模式与时间动态解耦
  - 与Koopman算子的关系
    - KMD是Koopman算子谱分解在有限维可观测量上的投影
    - 特征函数 $\varphi_j$ 是算子的特征函数，模态 $v_j$ 是其在可观测量上的投影
    - 任意有限个特征函数张成的空间是Koopman不变子空间

- Koopman谱理论的应用目标
  - 诊断：用Koopman谱性质表征高维复杂系统，实现降维与模型约简
  - 预测：提供对哪些可观测量易于/难于预测的洞察，给出鲁棒的时间序列预测算法
  - 估计与控制：通过Koopman特征函数的线性化视角，将线性估计与控制理论的成熟工具直接用于非线性系统
  - 不确定性量化：在传递算子框架下对强非线性和混沌系统的不确定性进行建模与管理
  - 理解：类比正规形理论，提炼动力学的本质结构信息，增进对复杂系统的直觉认知
  - 应用领域：流体力学、流行病学、神经科学、等离子体物理、金融、机器人、电网等

- 稳定性分析的算子视角
  - Lyapunov函数作为特殊观测量
    - Lyapunov函数是满足 $\mathcal{L}_f V(x) \leq 0$ 的非负观测量（$\mathcal{L}_f$ 为沿向量场 $f$ 的Koopman生成元）
    - 经典Lyapunov理论隐含使用了Koopman生成元的概念
    - 可由特征函数构造Lyapunov函数：$V(x) = (\sum_i |\varphi_i(x)|^p)^{1/p}$
  - 全局稳定性定理
    - 若特征函数 $\varphi_s$ 满足 $\text{Re}\{s\}<0$（$s$ 为对应特征值），则零水平集 $S_0=\{x|\varphi_s(x)=0\}$ 全局渐近稳定
    - 超越局部线性化的Lyapunov间接法，提供全局稳定性判据
    - 例：系统 $\dot{x}=-x^3$ 虽然无法局部线性化分析，但其广义特征函数 $\varphi(x)=\exp(-1/(2x^2))$ 对应特征值 $s=-1$，可判定全局渐近稳定
  - 特征函数的C¹性质与全局渐近稳定等价
    - 若不动点处Jacobian特征值实部全为负，且Koopman特征函数C¹，则系统全局渐近稳定
    - 将局部稳定性条件（Jacobian）与全局性质（特征函数光滑性）联系起来

- DMD：Koopman算子的数据驱动近似
  - 核心思想
    - 将无穷维Koopman算子 $\mathcal{K}$ 近似为有限维矩阵 $A$
    - 非线性状态转移 $x_{k+1} = F(x_k)$ 被线性化为 $x_{k+1} \approx Ax_k$
    - 纯数据驱动，无需方程，仅需状态快照序列
  - 算子到矩阵的映射
    - 选择测量子空间（通常 $g(x)=x$），将 $\mathcal{K}$ 限制为矩阵 $A: \mathbb{R}^n \to \mathbb{R}^n$
    - 假设存在近似Koopman不变子空间，使动力学在其上近似线性
    - 矩阵 $A$ 的谱分解给出Koopman特征值 $\lambda_j$ 和模态 $v_j$
  - 基本算法流程
    - 数据准备：构造快照矩阵对 $X=[x_1,\dots,x_m]$ 和 $X'=[x_2,\dots,x_{m+1}]$（$X'$ 为 $X$ 时移一步的版本）
    - 最优化：求解 $A = \arg\min_A \|X'-AX\|_F = X'X^\dagger$（$X^\dagger$ 为 $X$ 的伪逆，$\|\cdot\|_F$ 为Frobenius范数）
    - 降维：对 $X$ 做SVD得 $X = U_r \Sigma_r V_r^\top$，投影到秩 $r$ 子空间，计算 $\tilde{A} = U_r^* X' V_r \Sigma_r^{-1}$（$U_r \in \mathbb{R}^{n\times r}$ 为左奇异向量，$\Sigma_r$ 为奇异值对角阵，$V_r$ 为右奇异向量）
    - 谱分解：对 $\tilde{A}$ 特征分解得 $\Lambda$（特征值对角阵）和 $W$（特征向量矩阵）
    - 重构：精确DMD模态（Tu et al.）$\Phi = X'V_r\Sigma_r^{-1}W$，保证是完整矩阵 $A$ 的真实特征向量；投影模态 $\Phi = U_r W$ 不保证此性质，但在低秩结构下两者趋于一致
    - 幅值：$b = \Phi^\dagger x_1$（$b$ 为各模态的初始激发系数向量）
    - 预测：$x_k = \Phi \Lambda^{k-1} b$ 或连续时间 $x(t) = \sum_j \phi_j e^{\omega_j t} b_j$（$\phi_j$ 为第 $j$ 个DMD模态列向量，$\omega_j$ 为连续时间特征值，$b_j$ 为对应幅值）
  - DMD与Koopman谱的对应关系
    - DMD本质上是用伴随矩阵 $C$（满足 $X' = XC$）的谱来近似Koopman谱；$C$ 进一步分解为 $X' = XT^{-1}\Lambda_C T = V_K \Lambda_C T$，其中 $T$ 为由 $C$ 特征值构成的Vandermonde矩阵，$\Lambda_C$ 为 $C$ 的特征值对角阵，$V_K = XT^{-1}$ 即Koopman模态矩阵
    - DMD输出的模态 $v_j$ 并非纯粹的Koopman模态，而是被特征函数初值 $\varphi_j(x_0)$ 缩放后的结果，与KMD公式 $g(x_k) = \sum_j \lambda_j^k \varphi_j(x_0) v_j$ 对应
    - 局部有效性的根源：DMD假设快照矩阵列向量随快照数增加趋于线性相关，这等价于假设可观测量落在某有限维近似不变子空间内；若该子空间不由真正的Koopman特征函数张成，则仅在稳态附近弱非线性区域局部成立
  - 与传统方法的区别
    - POD/SVD：空间模态固定，时间系数非线性
    - 傅里叶变换：全局频率，无空间结构
    - DMD：空间相干结构+时间线性演化，自适应非线性动力学
  - 几何直观
    - 状态空间中的非线性轨迹通过"测量"投影到观测空间
    - 在观测空间中寻找最优线性近似 $z_{k+1}=Az_k$
    - 特征向量给出最佳线性化坐标系

- Koopman理论与经典动力系统的深层联系
  - 特征函数的几何意义
    - 水平集构成状态空间的不变分层结构
    - isostable（等稳线）：刻画收敛速率，类比"能量面"
    - isochron（等时线）：刻画相位信息，用于振荡器同步
    - 启示：特征函数不仅是代数工具，更是几何对象，编码了全局动力学结构
  - 对称性的利用
    - 若系统具有对称群 $\Gamma$，Koopman算子与群作用可交换
    - 可将Koopman矩阵块对角化，显著降低计算复杂度
    - 启示：物理对称性可直接转化为算法加速
  - Perron-Frobenius算子（概率视角）
    - Koopman算子的伴随，描述概率密度的演化
    - 两者谱相同，提供互补的计算路径
    - 启示：同一动力学可从"观测函数"或"概率分布"两个角度线性化
  - 超越特征值的谱理论
    - 混沌/湍流系统可能没有点谱（特征值），只有连续谱
    - 连续谱对应随机类行为，需要谱测度和谱投影等工具
    - 启示：并非所有系统都能用有限个特征函数精确描述，需要认识到Koopman近似的局限性
  - 广义特征函数与Jordan块结构
    - 耗散系统的非正规性
      - 保守系统（Hamilton）：Koopman算子酉，谱在单位圆上
      - 耗散系统：Koopman算子非酉且通常非正规，几何重数小于代数重数
    - 广义特征函数定义
      - 满足 $(\mathcal{K}-\lambda I)^m \xi = 0$（$m \geq 2$）而非 $(\mathcal{K}-\lambda I)\xi=0$
      - 连续时间演化：$\dot{\xi}_g^i = \lambda_g \xi_g^i + \xi_g^{i+1}$，形成Jordan链（$\xi_g^i$ 为第 $i$ 级广义特征函数，$\lambda_g$ 为对应特征值）
    - 物理意义
      - 捕捉非正规系统的瞬态放大效应（伪谱现象）
      - 对应流体力学中的非模态增长、能量放大机制
    - 在数据驱动方法中的应用
      - 需要广义特征函数才能张成完整的Koopman不变子空间
      - 通过非回归集的边界函数构造（Korda等人方法）
      - 块对角Jordan矩阵的连续时间表示及其离散化
  - 非自治与随机系统
    - 时变/随机系统可通过"扩展状态空间"或"期望算子"纳入Koopman框架
    - 启示：Koopman理论的适用范围远超自治确定性系统
  - PDE中的应用
    - Cole-Hopf变换、逆散射变换是显式Koopman算子的经典例子
    - 神经网络可学习类似变换，为非可积PDE提供数据驱动线性化
    - 启示：Koopman思想可推广到无穷维系统，连接经典数学物理与现代机器学习

- 数据驱动的观测量选择与嵌入
  - 核心动机
    - 强非线性系统在原始测量空间难以用线性算子近似
    - 需要将状态嵌入到更高维空间，在其中寻找近似线性结构
    - 关键问题：如何选择观测函数 $\{g_1(x), \dots, g_p(x)\}$ 张成近似Koopman不变子空间
  - Extended DMD（eDMD）：函数基提升
    - 构造增广状态 $z = [g_1(x), \dots, g_p(x)]^\top$，在提升空间执行DMD
    - 理论基础：Galerkin投影，通过函数基与残差正交来逼近Koopman算子
    - 常用函数基：多项式、径向基函数（RBF）、傅里叶基、混合基
    - 收敛性：在遍历动力学的长轨迹极限下收敛到Koopman算子的有限维投影
    - eDMD与特征函数的对应：定义字典函数向量 $\theta(x) = [\theta_1(x),\dots,\theta_k(x)]^\top$（$k$ 为字典函数个数），特征函数在此基下展开为 $\varphi_i(x) = \sum_{j=1}^k b_{ij}\theta_j(x)$，矩阵形式记为 $\varphi = B\theta$（$B \in \mathbb{R}^{n \times k}$，$n$ 为截断特征函数个数）；构造快照矩阵 $\Theta = [\theta(x_1),\dots,\theta(x_m)]$ 和 $\Theta' = [\theta(x_2),\dots,\theta(x_{m+1})]$，通过线性回归得Koopman算子近似 $\hat{K} = \Theta' \Theta^\dagger$，对角化为 $\hat{K} = P\Lambda P^{-1}$（$P$ 为右特征向量矩阵，$\Lambda$ 为特征值对角阵）；关键细节：$B$ 的行取自 $P^{-1}$ 的行（对偶/左特征向量），而非 $P$ 的列——混淆两者会导致错误的特征函数提取；设 $g(x) = D\theta(x)$（$D$ 为观测量在字典基下的系数矩阵），则Koopman模态由 $g = D\theta = DB^{-1}\varphi = V\varphi$ 给出（$V = DB^{-1}$ 为模态矩阵）
    - 关键风险：若字典函数基不张成Koopman不变子空间，会产生大量伪特征值和伪特征向量；且不能同时包含原始状态 $x$ 并表示具有多个不动点或周期轨道的系统（拓扑障碍），必须用交叉验证剔除伪模态
    - 挑战：高维诅咒、过拟合、函数基选择依赖经验
  - 拓扑共轭与特征函数学习
    - 理论基础
      - Schrödinger方程的多元推广：$\phi \circ F = F'(0)\phi$，解给出主特征函数
      - 拓扑共轭：若存在同胚 $d: d \circ F = T \circ d$，则两系统共享Koopman谱
      - 谱等价定理：线性系统 $T$ 的特征函数 $\psi$ 可通过 $\varphi = \psi \circ d$ 构造非线性系统 $F$ 的特征函数
    - 数据驱动实现
      - 学习微分同胚 $d(x)=x+h(x)$，其中 $h$ 满足PDE：$Th(x) - r(x) = \frac{\partial h}{\partial x}(Tx+r(x))$（$r(x)$ 为非线性余项，$T = F'(0)$ 为线性化矩阵）
      - 优化目标：$\min_{h(\cdot)} \sum_i \|\dot{d}_i - Td_i\|^2$，约束 $\frac{\partial h}{\partial x}(0)=0$
      - 从系统的线性化 $T=F'(0)$ 出发，递归构造高阶特征函数
    - 几何意义
      - $-h(x)$ 定义系统的不变流形
      - 将线性系统"扭曲"为非线性系统，保持谱结构不变
      - 利用Hartman-Grobman定理的全局扩展
    - 优势：直接构造真正的特征函数，而非近似不变子空间
  - 时延坐标嵌入（Hankel DMD / HAVOK）：时间维度提升
    - 基于Takens嵌入定理：从标量时间序列 $y(t)$ 构造时延向量 $[y(t), y(t-\tau), \dots, y(t-(d-1)\tau)]^\top$（$\tau$ 为时延步长，$d$ 为嵌入维度）
    - 构造Hankel矩阵，通过SVD提取近似Koopman不变子空间
    - HAVOK框架：混沌系统分解为线性部分 + 间歇性强迫
      $$\frac{d}{dt}v = Av + Bv_r(t)$$
      （$v$ 为SVD提取的主坐标向量，$A$ 为线性动力学矩阵，$B$ 为强迫矩阵，$v_r(t)$ 为间歇性强迫项）
    - $v_r$ 的统计分布是非高斯的（长尾），稀有事件对应Lorenz系统的叶瓣切换，给出混沌的可操作线性+强迫分解视角
    - 优势：仅需单一测量，无需先验知识，自动发现坐标系
    - 局限：需要长时间序列，对噪声敏感，参数（时延 $\tau$、嵌入维度 $d$）需调优
  - 扩散映射：流形几何视角
    - 通过数据点间的"扩散距离"（随机游走视角）度量流形上的测地距离
    - 构造亲和矩阵 $W_{ij} = \exp(-\|x_i-x_j\|^2/\epsilon)$（$\epsilon$ 为带宽参数），归一化后特征分解得扩散坐标
    - 与Koopman联系：扩散算子近似Laplace-Beltrami算子，扩散坐标近似调和函数
    - 应用：高维数据降维、流形学习、对噪声鲁棒的嵌入
  - 深度学习方法：神经网络自动学习嵌入
    - 深度自编码器：学习低维潜空间 $z=\varphi(x)$，约束其中动力学线性 $z_{k+1}=Az_k$，损失函数包含 $\|\varphi(x_{k+1}) - K\varphi(x_k)\|$（$K$ 为网络参数化的Koopman矩阵）
    - 高维提升网络：学习高维嵌入 $z=\varphi(x)$，在其中建立线性模型
    - 处理连续谱：引入辅助网络参数化依赖状态的特征值 $\lambda(x)$，避免用高次谐波展开频率偏移
    - 优势：表达能力强，端到端学习，可处理复杂系统
    - 挑战：需要大量数据，训练不稳定，可解释性差
  - 核方法（RKHS）：隐式无穷维提升
    - 通过核函数 $\kappa(x,y)$ 隐式定义高维特征映射，避免显式计算（此处用 $\kappa$ 与状态 $x$ 区分）
    - 核eDMD：在核空间中执行DMD，利用核技巧降低计算复杂度
    - 理论保证：RKHS提供函数逼近的严格框架，适当核选择下可任意精度逼近
    - 实践：核参数需交叉验证，可通过Nyström近似加速
    - 核eDMD的降维机制：$\hat{K}$ 的每个特征向量均在快照矩阵 $\Theta$ 的左奇异向量 $U$ 的列空间中，因此可将问题从 $k \times k$（字典维度，$k$ 可为无穷）压缩到 $m \times m$（快照数）；定义核矩阵 $A \in \mathbb{R}^{m\times m}$，其元素 $A_{ij} = \kappa(x_i, x_j)$（即字典函数的内积 $\theta(x_i)^\top \theta(x_j)$），以及Gram矩阵 $G = \Theta^\top \Theta$，满足 $G_{ij} = \kappa(x_i, x_j)$，两者均通过核函数隐式计算，使无穷维字典（如RBF核 $\kappa(x,y)=\exp(-\|x-y\|^2/\sigma^2)$ 对应无穷次多项式基）在实践中可计算
  - 观测量选择的指导原则
    - 物理直觉：优先选择守恒量、对称性相关量、领域知识（能量、动量等）
    - 数学准则：函数基稠密、避免线性相关、平衡表达能力与计算成本
    - 数据驱动：POD/PCA识别主导模态、互信息筛选特征、迭代优化策略
  - 实践要点
    - 数据预处理：归一化、去趋势、降噪
    - 模型验证：交叉验证、长期预测误差、物理一致性检查
    - 超参数调优：网格搜索或贝叶斯优化（函数基数量、正则化强度、网络结构）

- Koopman理论在控制中的应用
  - 控制系统的Koopman表示
    - 控制仿射系统的双线性化
      - 系统形式：$\dot{x} = f(x) + g(x)u$（$f(x)$ 为漂移向量场，$g(x)$ 为控制向量场，$u$ 为控制输入）
      - 关键条件：若控制向量场 $g$ 的特征函数在漂移场 $f$ 的特征函数张成空间中，即 $\text{span}\{\varphi_{c,i}\} \subseteq \text{span}\{\varphi_i\}$
      - 特征函数演化呈双线性形式：$\dot{\varphi}(x) = (L_f + L_g C u)\varphi(x)$，其中 $L_f$、$L_g$ 分别为沿 $f$、$g$ 的Lie导数，$C$ 为投影矩阵
      - 离散时间：$[\mathcal{K}(u)\varphi](x) = \mathcal{K}_f(\mathcal{K}_g C)^u\varphi(x)$，可用线性参数变化（LPV）理论处理
      - 特殊情况：若 $g$ 为常向量，任何漂移场自动满足条件
    - 一般非线性控制系统
      - 联合状态-输入特征函数：$\dot{\phi}(x,u) = L_f\phi(x,u) + \frac{\partial}{\partial u}\phi(x,u)\dot{u}$
      - 需要控制导数 $\dot{u}$ 作为输入（积分控制）
      - 状态膨胀技巧：引入 $\dot{v}=u$，将 $[x,v]$ 作为扩展状态，转化为控制仿射形式
    - 与反馈线性化的对比
      - 反馈线性化通过补偿抵消非线性，对模型误差敏感，可能破坏有用的稳定性非线性（如阻尼）
      - Koopman方法保留原系统非线性，仅在观测空间线性化，更鲁棒
      - Koopman方法便于处理任意代价泛函优化，反馈线性化后的系统不保持原优化结构
      - 实例：水下机器人的流体阻尼是稳定性来源，反馈线性化会导致过度控制
  - 模型预测控制（Koopman MPC）
    - 基本框架
      - 学习Koopman嵌入 $z = g(x)$ 和线性预测模型 $z_{k+1} = Az_k + Bu_k$（$z_k$ 为提升状态，$u_k$ 为控制输入，$A$、$B$ 为待辨识矩阵）
      - 在提升空间中求解线性MPC优化问题（二次规划）
      - 计算复杂度与观测量维度无关，可处理高维嵌入
    - 数据驱动建模方法
      - DMDc（含控制的DMD）：区分自然动力学与控制效应，$X' = AX + BU$（$U$ 为控制输入快照矩阵）
      - eDMDc：在非线性观测量空间中建立双线性模型
      - DDMDc（时延DMDc）：适用于仅有输入输出数据的情形
      - 深度Koopman控制：神经网络端到端学习嵌入与控制策略
    - 优势：可处理约束、多目标优化、滚动时域优化
    - 挑战：模型误差累积、鲁棒性保证、实时计算
  - 基于内禀特征函数的控制
    - 双线性控制模型
      - 利用无控制系统的Koopman特征函数 $\varphi(x)$ 作为坐标
      - 在特征函数坐标下，控制系统呈现双线性形式：$\dot{z} = \Lambda z + B(z)u$（$z = \varphi(x)$ 为特征函数坐标，$\Lambda$ 为特征值对角阵，$B(z)$ 为状态依赖的控制矩阵）
      - $\Lambda$ 为对角矩阵（特征值），$B(z)$ 为状态依赖的控制矩阵
    - 反馈线性化
      - 若 $B(z)$ 满足可控性条件，可通过状态反馈实现精确线性化
      - 设计线性控制器稳定化特征函数坐标系统
      - 适用于具有特殊结构的非线性系统（如机械系统、化学反应器）
    - 全局稳定性分析
      - Koopman特征函数可作为Lyapunov函数候选
      - 通过特征函数的水平集分析吸引域
      - 构造收缩度量，证明指数稳定性
  - 可观性与可控性分析
    - 线性化的可观性
      - 在提升空间中应用线性可观性秩判据
      - Koopman可观性Gramian：量化状态估计的信息增益
      - 应用：最优传感器布置、状态估计器设计
    - 线性化的可控性
      - 在提升空间中应用线性可控性秩判据
      - Koopman可控性Gramian：量化控制输入的能量效率
      - 应用：最优执行器布置、最小能量控制
    - 注意事项：提升空间的可观/可控性不等价于原系统的非线性可观/可控性
  - 状态估计（Koopman滤波）
    - 扩展卡尔曼滤波（EKF）的替代
      - 在Koopman线性化空间中应用标准卡尔曼滤波
      - 避免雅可比矩阵计算，适用于高维系统
    - 粒子滤波的加速
      - 利用Koopman预测模型减少粒子数量
      - 在线性化空间中传播不确定性
    - 数据同化：结合观测数据修正Koopman模型预测
  - 鲁棒控制与不确定性量化
    - 鲁棒MPC
      - 考虑Koopman模型的不确定性：$z_{k+1} = (A+\Delta A)z_k + Bu_k$（$\Delta A$ 为模型误差矩阵）
      - 通过管道MPC或随机MPC处理模型误差
      - 概率约束满足：保证状态以高概率留在安全集
    - 随机Koopman算子
      - 对随机动力系统，Koopman算子作用于期望：$\mathcal{K}g(x) = \mathbb{E}[g(F(x,w))]$（$w$ 为随机噪声）
      - 生成元包含扩散项，对应Fokker-Planck方程
      - 应用：风险敏感控制、机会约束优化
  - 实际应用案例
    - 流体控制：圆柱绕流减阻、边界层控制、湍流抑制
    - 机器人：非线性轨迹跟踪、接触力控制、欠驱动系统
    - 电网：频率调节、电压控制、负荷预测
    - 化学过程：反应器温度控制、批次优化
    - 生物系统：神经刺激、药物输送、疾病控制
  - 关键技术挑战
    - 模型质量：Koopman嵌入的准确性直接影响控制性能
    - 计算效率：高维嵌入的实时优化求解
    - 鲁棒性保证：模型误差、外部扰动、测量噪声的影响
    - 理论保证：闭环稳定性、约束满足、收敛性证明
    - 可解释性：神经网络学习的Koopman嵌入缺乏物理直观
  - 与传统非线性控制方法的比较
    - 反馈线性化：需要精确模型和特殊结构，Koopman方法更数据驱动
    - 滑模控制：Koopman MPC可自然处理约束和优化目标
    - 自适应控制：Koopman模型可在线更新，结合自适应思想
    - 学习控制：Koopman提供可解释的中间表示，连接模型与数据

- 神经算子（Neural Operator）：算子学习的深度学习视角
  - 核心问题定位
    - Koopman框架：给定系统 $F$，找特征函数使动力学线性化，关注谱结构
    - 神经算子框架：给定数据对 $\{a^{(i)}, u^{(i)}\}$，直接学习映射 $G_\theta \approx G^\dagger: \mathcal{A} \to \mathcal{U}$，不假设动力学结构
    - 典型场景：PDE的参数到解的映射，$a(x)$ 为系数函数，$u(x)$ 为解函数
    - 与Koopman的联系：若令 $a = x_0$（初始条件）、$u = x_t$（$t$ 时刻状态），则 $G^\dagger$ 即为flow map，其Koopman线性化正是前述框架的主题
  - 离散化不变性（核心新概念）
    - 传统神经网络参数与训练网格绑定，换分辨率需重新训练
    - 神经算子参数定义在函数空间层面，与具体离散化无关
    - 精确定义：给定域 $D$ 的离散细化序列 $(D_L)_{L=1}^\infty$，参数化算子族 $G(\cdot, \theta)$ 满足离散化不变性，若存在映射序列 $\hat{G}_L$ 使得对任意紧集 $K \subset \mathcal{A}$：
      $$\lim_{L\to\infty} \sup_{a \in K} \|\hat{G}_L(D_L, a|_{D_L}) - G(a, \theta)\|_{\mathcal{U}} = 0$$
    - 标准神经网络不满足此性质；图神经网络和Transformer仅满足分辨率不变性，不满足连续极限收敛性
  - 神经算子架构
    - 三步结构：提升 $\to$ 迭代积分核 $\to$ 投影
      $$G_\theta := Q \circ \sigma_T(W_{T-1} + K_{T-1} + b_{T-1}) \circ \cdots \circ \sigma_1(W_0 + K_0 + b_0) \circ P$$
    - 核心层为积分核算子：
      $$(K_t v_t)(x) = \int_{D_t} \kappa^{(t)}(x, y)\, v_t(y)\, d\nu_t(y)$$
    - 与标准神经网络的类比：矩阵乘法（有限维线性层）$\to$ 积分算子（函数空间线性层），非线性激活保持不变
    - 与Koopman的形式差异：Koopman算子是复合 $\mathcal{K}g = g \circ F$，神经算子的核 $\kappa$ 是学出来的，不对应任何特定动力学
  - 四种参数化方案
    - GNO（图神经算子）
      - 基于Nyström近似 + 域截断，用图神经网络实现
      - 截断积分：$u(x) = \int_{B(x,r)} \kappa(x,y) v(y)\, dy$
      - 复杂度 $O(J'^2)$，支持非结构网格
    - LNO（低秩神经算子）
      - 核函数张量积分解：$\kappa(x,y) = \sum_{j=1}^r \phi^{(j)}(x)\psi^{(j)}(y)$
      - 退化为有限秩算子：$u = \sum_j \langle \psi^{(j)}, v \rangle \phi^{(j)}$
      - 复杂度 $O(J)$；与KMD展开 $g = \sum_j \varphi_j(x) v_j$ 形式相同，但基函数由数据学出而非动力学决定
    - MGNO（多极图神经算子）
      - 多尺度核矩阵分解：$K = K_1 + K_2 + \cdots + K_L$，短程稀疏、长程低秩
      - V-cycle算法实现，复杂度 $O(J)$
    - FNO（傅里叶神经算子）
      - 在Fourier域直接参数化核：$u(x) = \mathcal{F}^{-1}[R_\varphi \cdot \mathcal{F}(v)](x)$
      - 截断至 $k_{\max}$ 个模式，利用FFT，复杂度 $O(J \log J)$
      - 与Koopman谱方法共享工具，但 $R_\varphi$ 是学出的权重张量而非谱算子
  - 通用逼近定理
    - 神经算子可在紧集上一致逼近任意连续算子 $G^\dagger: \mathcal{A} \to \mathcal{U}$
    - 适用空间：$L^p$、Sobolev空间 $W^{m,p}$、连续函数空间 $C^m(\bar{D})$ 等一般Banach空间
    - 误差分解：$\|\hat{G}_\theta(D_L, a|_{D_L}) - G^\dagger(a)\|_{\mathcal{U}} \leq \underbrace{\|\hat{G}_\theta - G_\theta\|}_{\text{离散化误差}} + \underbrace{\|G_\theta - G^\dagger\|}_{\text{逼近误差}}$
    - 两项均可通过加密网格和增加参数趋于零
  - 与其他方法的关系
    - DeepONet是神经算子在固定输入网格上的特例，本质是线性逼近（trunk net张成的线性空间），而神经算子是非线性逼近，表达能力更强
    - Transformer的self-attention是神经算子的特例：选取特定非线性核 $\kappa_v(v(x), v(y)) = g_v(\cdot) R$ 后，离散化即得标准注意力机制
    - 标准CNN是核支撑局部化 + 参数与网格绑定的特例，不满足离散化不变性
  - 实践性能
    - Darcy流：FNO相对误差约 $1\%$，优于所有基准
    - Burgers方程：FNO误差 $0.18\%$，比次优方法低约一个数量级
    - Navier-Stokes（$Re \approx 20$）：误差 $< 1\%$；推理速度比伪谱方法快约 $3$ 个数量级（$0.005\text{s}$ vs $2.2\text{s}$）
    - 零样本超分辨率：在低分辨率训练，直接在高分辨率推理，无需重新训练
    - 贝叶斯反问题：MCMC采样从 $18$ 小时压缩至 $2.5$ 分钟
  - 与Koopman框架的对比定位
    - Koopman：追求可解释的谱结构，假设动力学存在，适合分析与控制
    - 神经算子：追求高精度端到端逼近，完全数据驱动，适合大规模PDE求解加速
    - 两者可结合：用神经算子学习flow map，再对其做Koopman谱分析，兼顾精度与可解释性
